# Image Usage Rules

## ใช้รูปภาพของจริงก่อนเสมอ

- **ห้ามสร้างรูปภาพด้วย AI (generate_image)** เว้นแต่จะไม่มีรูปจริงเลยและได้รับการอนุมัติจากเจ้าของโปรเจกต์ก่อน
- รูปภาพของจริงอยู่ที่ `/public/images/` — ให้ใช้จากโฟลเดอร์นี้เป็นหลัก
- ก่อนสร้างรูปใหม่ ให้ตรวจสอบ `/public/images/` ว่ามีรูปที่เหมาะสมอยู่แล้วหรือไม่
- รูปที่มีอยู่ในโปรเจกต์:
  - `royal_thai_massage.jpg` — นวดไทย
  - `sports_massage_promo.jpg` — นวดออฟฟิศ / กีฬา
  - `aroma_massage_service.jpg` — นวดอโรมา
  - `foot_massage_service.jpg` — นวดเท้า
  - `herbal_compress_massage.jpg` — นวดลูกประคบ / สมุนไพร
  - `interior_sneak_peek.jpg` — บรรยากาศภายในร้าน
  - `interior_lobby.png` — ล็อบบี้ร้าน
  - `logo.png` — โลโก้ร้าน
  - `massage_bed_atmosphere.jpg` — บรรยากาศเตียงนวด
  - และอื่นๆ ใน `/public/images/`
